## 1. 两张设计图是什么关系

这两张图代表了同一套界面排版分别在「浅色纸质」与「深色仪器」两档视觉场景下的具体实现，这种设计思路与播放器需要支持的浅色、深色两套主题非常契合。两者在结构与视觉呈现上的具体特征如下：

**版式结构**
  - 两张图共用了一套完全一致的版式网格系统：左上角字标位置与尺寸一致，右上角小标签、左下角说明文字、右侧文字列以及分割细线的布局坐标也几乎完全重合。
  - 左上角字标内容确认均为 **RHINELAB**，字体采用全大写、粗体的中性无衬线风格。

**色彩与视觉质感**
  - 浅色版本（图 A）选用偏暖的白色底色模拟纸面，搭配略带暖调的黑色墨线与黄铜色强调色，呈现出类似纸质印刷品、档案卷宗及纸质技术文档的质感。
  - 深色版本（图 B）以带有青石板质感的蓝黑色为基底，搭配冷白色文字与大面积散开的柔和光晕，呈现出物理仪器仪表和夜间工作终端的视觉感受。

### 3.1 强调色说明

**色彩基准与多主题表现**

海报浅色版本中的黄铜色 `#C5A974` 仅为贴合印刷效果的近似值；项目基准值来自 Blender 材质 Champagne_Index `#A3754A`（金属度 0.48 的香槟铜），已作为主强调色在界面落地。深色版本受整体泛光特效（bloom）影响，该位置会被冲淡呈现为冷银灰 `#CED1D6`。为保持品牌视觉一致，深色主题实现时仍沿用香槟色，仅将衬托底色调整为青石板色。

**强调色体系构成**

界面强调体系由以下三组颜色配合构成：

  - 主强调色：香槟色 `#A3754A`，作为核心强调应用。
  - 活跃状态色：琥珀色 `#7A2E0D`，用于表现组件点亮或正在播放等状态。
  - 结构质感：钛色 `#94999C`，专门用于绘制金属质感细边框。
## 4. 字体

- 标志中的字标采用中性无衬线体（grotesque，指笔画粗细均等、去除了多余装饰的早期无衬线风格），排版时统一使用粗体和全部大写字母，并且将字符间距微微拉宽，避免紧凑带来的压迫感。笔画特征上，大写字母 R 的右斜腿设计为笔直延伸，E 的三道横向笔画长度保持完全一致，A 的顶端为锐利的尖顶，B 则由上下两个弧度分明的双碗结构组成。正文部分选用较细字重的小号字，配合偏大的行距，使段落之间形成开阔而充分的留白，整体呈现出严谨、清晰的技术文档气质。
- 播放器内已经预先集成了 MiSans 字体，该字体同样属于中性无衬线风格，视觉特征与参考效果完全契合。在渲染字标位置的文本时，只要把样式配置为粗体、全部转换为大写形式并适当调大字间距，就能够准确还原设计目标。

### 5.1 终端界面里的播放器**不**用上表配色

上文列出的材质映射表，适用的范围仅限于拥有完整独立视窗的**独立播放器界面**主题系统。当播放器以内嵌模块的形式置入莱茵生命终端主界面内部时，不能套用这张色彩映射表。这是因为终端主界面在既有规范中已经具备一套内部自洽的视觉色彩体系；如果内嵌播放器在此时自行引入另一套调色板，例如过去尝试采用过的黄铜色 `#C5A974`，就会在宿主界面里产生明显的视觉割裂，破坏界面的统一感。

嵌入在终端界面内部的播放器组件，其各项界面元素必须统一遵循以下色彩取值：

| 角色 | 取值 |
| --- | --- |
| 纸面底色 | `#e8e5e1` |
| 浮层面板 | `rgba(237,235,228,.94)` |
| 输入/按钮底 | `#f5f2e9` |
| 细线 | `#c1b8a7` / `#bdb8ad` / `#a6a49c`（按钮描边、标签下边线、按键） |
| 实心深色 | `#252820`（文字 `#f0eee5`，副文字 `#bcbfb1`） |
| 主文字 / 正文 / 弱化 | `#171713` / `#5a584e` / `#807b70` / `#9a9487` |
| 暖色强调 | `#9b7247`（悬停）/ `#a67d48`（焦点框） |
| 橄榄强调 | `#565c46`（强调色、设置项主按钮） |
| 夜态家族 | `#252820` / `#30362a` / `#4b4a3b` |

开发与样式落地时需要明确：**在终端界面中，决定组件视觉样式的单一真实来源始终是终端自身既有的全局样式表，而不是这两张参考设计图。**这两张设计图在落地过程中的参考边界如下：

**结构与版式参考**
  - 组件与线条：使用锐利的直角边缘配合 1px 的精细分界线。
  - 文字与排版：功能标签采用英文全大写小号字，数值排布使用对齐方便的等宽数字。
  - 布局与指引：留出充足操作间距的大面积留白，并配置侧边的竖向信息索引条。

**色彩应用约束**
  - 设计图自带的色彩十六进制数值效力仅局限在独立播放器界面中，不能向终端主界面内反向渗透。
