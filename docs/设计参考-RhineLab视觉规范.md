## 1. 两张设计图是什么关系

- 两图**共用同一套版式网格**：左上角字标（同位置、同尺寸）、右上角小标签、
  左下角说明文字、右侧文字列、细线分隔，位置几乎完全重合。
- 字标经字形判读为 **RHINELAB**（中性无衬线、粗体、全大写）。
- 浅色版（图 A）：暖白纸面 + 暖黑墨线 + 黄铜强调，是「纸张 / 档案 / 技术文档」气质。
- 深色版（图 B）：青石板蓝黑 + 冷白文字，配大面积柔和光晕（bloom），是「仪器 / 夜间终端」气质。
- 结论：**同一套设计在「浅色纸张」与「深色仪器」两档主题下的表达**，正适合播放器的浅/深主题。

### 3.3 强调色说明

- 海报浅色版的黄铜 `#C5A974` 是「印刷品」的近似表达；**权威值是 Blender 材质
  Champagne_Index `#A3754A`**（金属 0.48 的香槟铜），已作为 `--accent` 落地。
- 深色版因整体 bloom 发光，同一位置被压成冷银灰 `#CED1D6`；为保持品牌一致，
  播放器深色主题仍用香槟 `#A3754A`，只把底色换成青石板。
- 强调体系三件套：香槟 `#A3754A`（主强调）· 琥珀 `#7A2E0D`（点亮/播放态）· 钛 `#94999C`（金属描边）。

## 4. 字体

- 字标为**中性无衬线（grotesque）**，粗体全大写，字母间距略松；R 直腿、E 三横等宽、A 尖顶、B 双碗。
- 正文为细体小字，行距大，留白充分，技术文档气质。
- 播放器落地：`app-rhine` 已内置 **MiSans**（同类中性无衬线），与参考气质一致；
  字标处加 `letter-spacing`、全大写、粗体，即可还原。

版式细节（直角组件、1px 细线、等宽数字、封面四角标记、香槟强调）沿用既有
`:root[data-theme="rhine"]` 那段「仪器面板」材质；浅色主题 `rhine-light` 走同款材质但换
Blender 纸面配色（磨砂白 + 象牙 + 碳黑墨）。主题系统里 `--rl-brass` 即香槟
`#A3754A`、`--rl-brown` 即索引 `#AB8766`、`--rl-amber` 即琥珀 `#7A2E0D`、
`--rl-titanium` 即钛 `#94999C`。

### 5.1 重要修订：终端界面里的播放器**不**用上表配色

上面这张表用于**独立播放器界面**（`app/index.html`）的主题系统。
以莱茵生命终端为底座的主界面（`app-rhine/`）**不套这张表** —— 终端本身已经有一套
自洽的配色，播放器若另起一套（曾用过上面推导出的黄铜 `#C5A974`），
在终端里就会明显割裂（用户："界面下方的播放栏风格与UI风格十分割裂"）。

终端界面里播放器必须使用的令牌（直接取自 `app-rhine/src/style.css` 的既有取值）：

| 角色 | 取值 | 终端里的出处 |
| --- | --- | --- |
| 纸面底色 | `#e8e5e1` | `:root { background }` / `#stage` |
| 浮层面板 | `rgba(237,235,228,.94)` | `.terminal-modal` 的 `rgba(237,235,228,.97)` |
| 输入/按钮底 | `#f5f2e9` | `.solid-button` 的相邻按钮样式 |
| 细线 | `#c1b8a7` / `#bdb8ad` / `#a6a49c` | 按钮描边、`.detail-tabs` 下边线、`.key` |
| 实心深色 | `#252820`（文字 `#f0eee5`，副文字 `#bcbfb1`） | `.solid-button` |
| 主文字 / 正文 / 弱化 | `#171713` / `#5a584e` / `#807b70` / `#9a9487` | `.metadata`、`.detail-tabs`、`.detail-footnote` |
| 暖色强调 | `#9b7247`（悬停）/ `#a67d48`（焦点框） | `.system-nav button:hover`、`input:focus-visible` |
| 橄榄强调 | `#565c46` | `accent-color`、`.settings-list` 主按钮 |
| 夜态家族 | `#252820` / `#30362a` / `#4b4a3b` | `.toast`、`.solid-button:hover` |

一句话：**在终端里，"风格"的权威源是终端自己的 `style.css`，不是这两张设计图。**
设计图的价值在于版式语言（直角、1px 细线、全大写小字标签、等宽数字、大面积留白、
竖向索引条），配色只在独立播放器界面里生效。
