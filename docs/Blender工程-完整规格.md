> **来源署名：这套 Blender 工程与配套 UI 源码均由 B 站 UP 主 [@路北路陈](https://space.bilibili.com/3546646728820438) 制作**（仓库 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)，MIT）。本仓库的工作只能涵盖反向整合与各项参数的核对，模型、贴图这类美术资产的著作权依然归原作者所有。
>
> 相关数据全部提取自原作者公开发布的源码与 Blender 工程压缩包（遵循 MIT 协议，日期标注为 2026-09-09）。该工程内部包含专用的构造脚本，能够依靠代码程序化生成对应的 `.blend` 场景工程文件，随后再统一导出为 `app/assets/archive-*.glb` 模型文件供运行时加载。本文件集中整理了从这些资源中逆向读取出来的完整工程规格，后续如果要直接拿导出的 Blender 文件当成底层骨架来搭建播放器界面，必须以此处的记录作为唯一的核对依据。
## 1. 资产关系

| 产物 | 作用 |
| --- | --- |
| `archive-cassette.glb` | 单体「档案磁带」：一块 5×3.7 的磨砂玻璃面板 |
| `archive-assembly.glb` | 同几何，按 `assemblyPart` 拆成 6 部件（可拆解） |
| `rhine-archive.blend` + `archive-studio.png` | 摄影棚：正交相机 + 3 盏柔光 + 暖色世界 |
| 内构 | 两环光学腔体、琥珀环、双连接带、细立筋 |
| 外壳 | 外框刻线、压槽、两枚钛螺丝、顶部黄铜凹槽 |
| 细节 | 竖排凸字、底部对角排气、服务插座、注册垫片 |

项目中用到的三维模型与渲染场景资产按照结构层级和呈现需求进行划分，各文件与几何组件的具体对应关系如上表所示。

整个模型体系由两个核心交付文件以及配套的布光环境工程构成。其中 `archive-cassette.glb` 作为单一整体模型输出，呈现的是规格尺寸为 5×3.7 的磨砂玻璃面板整体外观，便于在不需要内部拆解动画的普通展示场景中快速加载；`archive-assembly.glb` 保持完全一致的几何外形，但利用自定义属性 `assemblyPart` 把模型明确拆分成 6 个独立部件，当用户在交互中触发爆炸图或结构拆解功能时，可以分别控制这些部件的位置移动。Blender 源文件 `rhine-archive.blend` 配合环境贴图 `archive-studio.png` 共同构成统一的渲染摄影棚，内部放置用于消除透视形变的正交相机，布置了 3 盏提供漫反射照明的柔光灯，并搭配暖色世界环境节点来烘托整体画面的色调。

在几何体的细节拆分上，模型涵盖了三套层次分明的结构组合：
- 内构组件由两个环状的光学腔体、环绕分布的琥珀环、双连接带以及多根细立筋骨架拼合而成，构成了磁带内部的光学与力学支撑核心；
- 外壳部分由带有外框刻线和表面压槽的壳体板件组装，并通过两枚钛螺丝紧固，顶部开设有容纳接口接触的黄铜凹槽；
- 细节层级则包含外表面的竖排凸字标示、分布在底部对角位置的排气结构、供外部调试连接的服务插座，以及用于精准校对装配间隙的注册垫片。

## 3. 面板几何（单位米，坐标 (x, y=深度, z)）

- 面板整体尺寸为 **5.000 × 3.700**，对应的宽高比例约为 **1.35 : 1**，在视觉上呈现为横向展开的长方形轮廓。三维坐标系将 y=0 平面定义为最外层盖板的前表面基准，面板的内部构造由此沿着 -y 轴的负方向朝深处层层递进堆叠。
- 处在最前端的前磨砂盖板中心点坐标是 `(0,-.095,1.85)`，三维尺寸设定为 `5 × .016 × 3.7`；排在其后的组件分别是尺寸为 `4.97×3.68` 的后透光载板，以及尺寸为 `4.80×3.47` 的信息基板，四周边沿还配合安装了四条经过镜面打磨的抛光围栏来封闭结构。
- **大光学腔**：整个腔体的中心坐落在 `(-.425, 1.80)`，其外侧主环的外半径测得约为 .918；主环向外延伸出折射肩并连接内斜面，斜面表层切削出 3 圈同心车削线和多条径向接缝，侧壁四周则紧密排列着 84 根垂直方向的细立筋。
- **小光学腔**：此腔体定位在右上区域的 `(1.125, 2.455)` 坐标处，外半径规格约为 .555；腔内同心套嵌着琥珀环与中央轮毂结构，环绕其侧壁的外圈均匀分布着 52 根竖直立筋。
- **琥珀环**：大尺寸的琥珀环被切分为两段分离的弧形部件，分布的夹角区间分别是 109°–225° 和 229°–364°，小尺寸的琥珀环则由一段完全封闭的整圆及其底部延伸的束带结构组合而成，整套构件在显示层面上专门用来承载界面的「进度环」动画。
- **光学双连接带**（ribbon）：这一构造由两根透光度极高的高透明材质柔性条带构成，在空间中顺次穿过左下方的 `(0.31,1.16)→(0.99,1.33)→(1.00,1.78)→(0.73,2.20)` 等关键点位，持续延展到面板的右上区域；为了固定走向并在光线穿过时形成连续反射，每个拐角转折位置都开凿了与条带相切的导槽，负责向用户动态呈现「音频流」的可视化数据。
- **序列标签块**（左上）：该模块固定在面板左上方的 `(-1.36, 3.04)` 位置，占用面积为 `.99×.41` 的物理空间，构件正面自上而下排布着 "RHINE LAB, LLC."、"INTERNAL DATABASE" 与 "NO.001" 这三行说明字符。**黄铜索引条**是处于左上角 `case_point(92,26)` 坐标处的一条竖直金属嵌条，表面指定了 `Index_Inlay` 材质后顺着外框的左侧边缘向下笔直延伸，专门用来展示品牌特征，或者作为用户界面中当前选中项的高亮提示。
- **外框刻线**：线雕凹槽均匀刻划在外上左、外下右、上电路、左勾、内框、下回返以及底搭扣等多个边缘位置，开凿的缝隙内壁附带一道细致的压槽高光以强化边缘立体感。**两枚钛螺丝**的固定孔分别钻在右上角的 `(999,37)` 与左下角的 `(57,642)` 这两处像素位置，两处沉孔的外周都环绕着半包围的 C 形压槽，螺帽顶部开有标准十字槽供装配定位。
- **校准刻度**：外框最左侧的竖直边缘整齐加工了 25 条短刻线，并且每隔 5 条短线就会插入一条长度更长的主刻线，用这种间隔规律来指示时间轴进度与标尺读数。**排气**：右下角区域整合了 16 条细密的激光蚀刻排与 11 条倾斜布置的对角排气槽，这组开槽结构在界面交互时会兼作音频的频谱条跳动变化。
- **竖排凸字**：标识文字 "RHINE LAB, LLC." 以凸出表面的浮雕形式直接在左侧边框模塑成型，采用从上到下的竖直顺序排列。**服务插座**：装配在右下角像素坐标 `(1312,923)` 的位置，外观表现为一个带有香槟色金属内芯的圆形孔位，供用户点击来调出设置与系统菜单。**注册垫片**：安装在 `(-1.61,-1.45)` 坐标处，内部由两块香槟色的小规格方形垫块贴合而成。
## 4. 摄影棚

- 相机对象 `Asset_Review_Camera`：投影模式选择正交投影（ORTHO），也就是平行光线投影、不产生透视汇聚的成像方式。机身坐标固定在 `(-7,-11,6)`，镜头朝向中心目标点 `(0,0,1.9)`，并将正交缩放参数 `ortho_scale=7.3` 写入设置。这一机位位于主体的前左上方，能够以经典的三分之四侧俯视角度覆盖整体轮廓；因为去除了近大远小的透视形变，整台终端设备可以在保留合理边距的前提下，工整居中地呈现在渲染视口内。
- 世界环境 `Warm_Studio_World`：环境背景应用了偏向暖灰基调的色彩，浮点 RGB 数值填入 `(.8,.77,.72)`，对应十六进制色号 #CCC4B8，环境发光强度（Strength）则指定为 .65，用以提供基础的漫反射照度。
- 场景内布置了 3 盏面光（AREA 盘灯），各光源的照射方向统一对准坐标点 `(0,0,2)` 汇聚：主光 Softbox_Key 架设在 `(-4,-5,8)`，发光功率设为 950W，发光体尺寸 size 为 7；轮廓光 Softbox_Rim 放置在后方的 `(5,1,6)` 处，以 1100W 的功率和尺寸 size 为 5 的盘面勾勒模型边缘；补光 Softbox_Fill 设在 `(1,-7,3)`，功率控制在 350W，尺寸 size 设为 6，负责照亮背光处的暗部细节。
- 渲染器启用基于物理光线追踪的 Cycles 引擎，渲染采样数配置为 48 步，并同步开启内置的降噪处理流程来压制噪点，最终导出的成品图像分辨率为 1200×1000。
## 5. 终端 → 播放器界面 映射

这一节将硬件终端上的机械与光学部件，逐一对应到软件播放器的界面元素上。设计时把实体外壳的结构特征直接转译成了功能控件，让界面既保留工业仪器的质感，又能承担日常的媒体播放操作。下表列出了具体的映射关系：

| 终端部件 | 播放器功能 |
| --- | --- |
| 磨砂盖板（透射 .78） | 全屏画布 / 内容底下的柔焦 |
| 大光学腔（左上主环） | 主显示：封面 + 频谱可视化 |
| 琥珀环（大环弧段） | 播放进度环（随进度填充） |
| 小光学腔（右上） | 时间 / 状态读数（已播 · 总长） |
| 序列标签块（左上） | 歌曲信息：曲名 / 艺人 / 专辑 / 序号 |
| 黄铜索引条（左缘） | 当前播放高亮条 / 播放指示 |
| 校准刻度（左缘 25 格） | 进度条（可点选） |
| 排气槽（右下） | 频谱条（均衡器） |
| 双连接带（ribbon） | 音频流动光带 |
| 服务插座（右下圆孔） | 设置 / 菜单 |
| 两枚钛螺丝 | 上一首 / 下一首 |
| 竖排凸字（左缘） | 品牌 / 播放列表名 |
## 6. 落地原则

- 播放器界面的主体呈现即为这台档案终端本身。程序在运行时会直接加载并渲染三维模型文件 `archive-assembly.glb`，场景内的相机参数与灯光布局完全复刻第 4 节的内容，三维网格所涉及的各项材质属性则依序取用第 2 节列出的十六进制颜色代码 hex 色值，以此保证光影效果与设计稿完全一致。
- 二维文字图层与可交互控件需要精准对齐到终端对应的各个结构部件之上，避免元素出现错位。界面文字在深色背景下使用 `#EFF1F2` 呈现浅色，在浅色背景下使用 `Carbon_Ink #060706` 呈现深色；用户触发交互高亮时使用 `Champagne_Index #A3754A`，播放状态与进度充填则使用 `Amber_Optical_Inlay #7A2E0D` 产生点亮效果。底层的逻辑实现完整保留现有的 Electron 架构，针对本地曲库、网易云音乐（NCM）、B 站音频解析、系统全局媒体键以及底层音频输出等接口，均维持原有调用方式不做更改，从而确保播放核心功能的稳定性。
