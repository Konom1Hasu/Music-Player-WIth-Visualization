# Blender 工程完整规格（档案终端 = 播放器界面基础）

> **来源署名：这套 Blender 工程与配套 UI 源码均由 B 站 UP 主 [@路北路陈](https://space.bilibili.com/3546646728820438) 制作**（仓库 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)，MIT）。本仓库的工作只能涵盖反向整合与各项参数的核对，模型、贴图这类美术资产的著作权依然归原作者所有。

**资产来源与产出流程**
  - 数据提取自原作者公开发布的源码与 Blender 工程压缩包（遵循 MIT 协议，日期标注为 2026-09-09）。
  - 工程内置专用构造脚本，通过代码程序化生成 `.blend` 场景工程文件，并统一导出为 `app/assets/archive-*.glb` 模型文件供运行时加载。

**文档定位**
  - 本文件集中整理了从上述资源逆向提取的完整工程规格。若后续直接采用导出的 Blender 文件作为底层骨架搭建播放器界面，必须以此处的记录作为唯一核对依据。
## 1. 资产关系

| 产物 | 作用 |
| --- | --- |
| `archive-cassette.glb` | 单体「档案磁带」：一块 5×3.7 的磨砂玻璃面板 |
| `archive-assembly.glb` | 同几何，按 `assemblyPart` 拆成 6 部件（可拆解） |
| `rhine-archive.blend` + `archive-studio.png` | 摄影棚：正交相机 + 3 盏柔光 + 暖色世界 |
| 内构 | 两环光学腔体、琥珀环、双连接带、细立筋 |
| 外壳 | 外框刻线、压槽、两枚钛螺丝、顶部黄铜凹槽 |
| 细节 | 竖排凸字、底部对角排气、服务插座、注册垫片 |

项目中用到的三维模型与渲染场景资产按照结构层级和呈现需求进行划分，各文件与几何组件的具体对应关系如上表所示。

**核心交付资产**

项目由两个核心交付模型与配套渲染工程组成，用于适配不同的展示与拆解交互需求：

  - `archive-cassette.glb` 作为单一整体模型，呈现规格尺寸为 5×3.7 的磨砂玻璃面板外观，用于无需拆解动画的普通展示场景快速加载。
  - `archive-assembly.glb` 保持完全一致的几何外形，但按自定义属性 `assemblyPart` 拆分为 6 个独立部件，支持爆炸图或结构拆解时的单独位移控制。
  - `rhine-archive.blend` 与环境贴图 `archive-studio.png` 构成统一渲染摄影棚，内置正交相机、3 盏柔光灯以及暖色世界环境节点。

**几何结构拆分**

在几何体的细节拆分上，模型涵盖三套层次分明的结构组合：

  - 内构包含两环光学腔体、琥珀环、双连接带与细立筋骨架，构成磁带内部的光学与力学支撑核心。
  - 外壳由带有外框刻线和表面压槽的板件构成，顶部开有黄铜凹槽，并通过两枚钛螺丝紧固。
  - 细节补充了外表面的竖排凸字标示、底部对角排气结构、外部调试用的服务插座，以及用于精准校对装配间隙的注册垫片。

## 3. 面板几何（单位米，坐标 (x, y=深度, z)）

面板整体尺寸为 **5.000 × 3.700**，宽高比约为 **1.35 : 1**，呈现横向展开的长方形轮廓。三维坐标系将 y=0 平面定义为最外层盖板的前表面基准，内部构造沿 -y 轴负方向朝深处层叠堆叠。

处在最前端的前磨砂盖板中心点坐标是 `(0,-.095,1.85)`，尺寸为 `5 × .016 × 3.7`；其后依次为尺寸 `4.97×3.68` 的后透光载板与 `4.80×3.47` 的信息基板，四周边沿配合安装了四条镜面抛光围栏封闭结构。

#### 光学腔与动态显示组件

光学系统主要由双腔体、进度环及音频光带构成：

  - **大光学腔**：中心位于 `(-.425, 1.80)`，外侧主环外半径约 .918，主环向外延伸出折射肩并连接内斜面；斜面表层切削有 3 圈同心车削线和多条径向接缝，侧壁紧密排列 84 根垂直细立筋。
  - **小光学腔**：定位在右上区域 `(1.125, 2.455)` 处，外半径约 .555，腔内同心套嵌琥珀环与中央轮毂结构，侧壁外圈均匀分布 52 根竖直立筋。
  - **琥珀环**：负责承载界面「进度环」动画。大尺寸环切分为 109°–225° 和 229°–364° 两段分离弧形部件；小尺寸环则由一段封闭整圆及其底部延伸的束带结构组合而成。
  - **光学双连接带（ribbon）**：由两根高透材质柔性条带构成，顺次穿过 `(0.31,1.16)→(0.99,1.33)→(1.00,1.78)→(0.73,2.20)` 等点位延展至右上区域；拐角转折处均开有相切导槽以固定走向并形成连续反射，用于动态呈现「音频流」可视化数据。

#### 边框构造与装配细节

外框边缘包含多处功能性刻线、紧固件与指示刻度：

  - **刻线与排气结构**：线雕凹槽均匀分布在外上左、外下右、上电路、左勾、内框、下回返与底搭扣等边缘，内壁附带压槽高光；右下角区域整合了 16 条激光蚀刻排与 11 条倾斜对角排气槽，兼作音频交互时的频谱跳动条。
  - **螺丝与垫片固定**：两枚开有标准十字槽的钛螺丝分别固定在右上角 `(999,37)` 与左下角 `(57,642)` 像素位置，沉孔外周环绕半包围 C 形压槽；`(-1.61,-1.45)` 坐标处另装配由两块香槟色小方垫贴合而成的注册垫片。
  - **校准刻度**：外框最左侧竖直边缘加工有 25 条短刻线，每隔 5 条设有一条较长的主刻线，用于指示时间轴进度与标尺读数。

#### 标识与交互界面构件

面板各区域设置了品牌标识与功能性操作点位：

  - **序列标签与品牌文字**：左上方 `(-1.36, 3.04)` 处设有 `.99×.41` 的序列标签块，正面排布 "RHINE LAB, LLC."、"INTERNAL DATABASE" 与 "NO.001" 三行字符；左侧边框上另模塑有竖排凸字浮雕标识 "RHINE LAB, LLC."。
  - **黄铜索引条**：位于左上角 `case_point(92,26)` 坐标处，表面指定为 `Index_Inlay` 材质并沿外框左缘向下延伸，用作展示品牌特征或指示界面当前选中项。
  - **服务插座**：装配在右下角像素坐标 `(1312,923)` 处，外观为带有香槟色金属内芯的圆形孔位，供点击调出设置与系统菜单。
## 4. 摄影棚

本节配置摄影棚的相机视角、环境照明、三点布光以及最终渲染参数。

**视口与相机**
  - 相机对象 `Asset_Review_Camera`：采用正交投影（ORTHO），机身坐标固定在 `(-7,-11,6)`，镜头对准中心目标点 `(0,0,1.9)`，正交缩放参数 `ortho_scale=7.3`。该机位处于主体前左上方，以经典三分之四侧俯视角度覆盖整体轮廓，消除透视形变，使设备工整居中且保留合理边距。

**环境与照明**
  - 世界环境 `Warm_Studio_World`：背景采用暖灰基调，浮点 RGB 设为 `(.8,.77,.72)`（十六进制色号 #CCC4B8），发光强度（Strength）指定为 .65，提供基础漫反射照度。
  - 面光系统：场景内配置 3 盏面光（AREA 盘灯），照射方向统一对准坐标点 `(0,0,2)` 汇聚。
    - 主光 Softbox_Key：架设在 `(-4,-5,8)`，功率 950W，发光体尺寸 size 为 7。
    - 轮廓光 Softbox_Rim：架设在后方 `(5,1,6)`，功率 1100W，尺寸 size 为 5，用于勾勒模型边缘。
    - 补光 Softbox_Fill：架设在 `(1,-7,3)`，功率 350W，尺寸 size 为 6，负责照亮背光暗部细节。

**渲染设置**
  - 渲染器启用基于物理光线追踪的 Cycles 引擎，渲染采样数设为 48 步，同步开启内置降噪处理，输出分辨率为 1200×1000。
## 5. 终端 → 播放器界面 映射

这一节将硬件终端上的机械与光学部件，逐一对应到软件播放器的界面元素上。设计时把实体外壳的结构特征直接转译成了功能控件，让界面既保留工业仪器的质感，又能承担日常的媒体播放操作。下表列出了具体的映射关系：

| 终端部件 | 播放器功能 |
| --- | --- |
| 磨砂盖板（透射 .78） | 全屏画布 / 内容底下的柔焦 |
| 大光学腔（左上主环） | 主显示：封面 + 频谱可视化 |
| 琥珀环（大环弧段） | 播放进度环（随进度填充） |
| 小光学腔（右上） | 时间 / 状态读数（已播 · 总长） |
| 序列标签块（左上） | 歌曲信息：曲名 / 艺人 / 专辑 / 序号 |
| 黄铜索引条（左缘） | 当前播放高亮条 / 播放指示 |
| 校准刻度（左缘 25 格） | 进度条（可点选） |
| 排气槽（右下） | 频谱条（均衡器） |
| 双连接带（ribbon） | 音频流动光带 |
| 服务插座（右下圆孔） | 设置 / 菜单 |
| 两枚钛螺丝 | 上一首 / 下一首 |
| 竖排凸字（左缘） | 品牌 / 播放列表名 |
## 6. 落地原则

**三维场景渲染**
  - 播放器界面的主体呈现即为档案终端本身。程序在运行时直接加载并渲染三维模型文件 `archive-assembly.glb`，场景内的相机参数与灯光布局完全复刻第 4 节的内容，三维网格材质属性依序取用第 2 节列出的十六进制颜色代码 hex 色值，以保证光影效果与设计稿完全一致。

**界面交互与视觉规范**
  - 二维文字图层与可交互控件需精准对齐到终端对应的各个结构部件之上，避免元素错位。
  - 文字在深色背景下使用 `#EFF1F2`、浅色背景下使用 `Carbon_Ink #060706`；交互高亮统一采用 `Champagne_Index #A3754A`，播放状态与进度充填则使用 `Amber_Optical_Inlay #7A2E0D` 呈现点亮效果。

**底层架构与功能兼容**
  - 完整保留现有的 Electron 底层架构，本地曲库、网易云音乐（NCM）、B 站音频解析、系统全局媒体键以及底层音频输出等接口均维持原有调用方式不做更改，确保播放核心功能的稳定性。
