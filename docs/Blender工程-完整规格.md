## 3. 面板几何（单位米，坐标 (x, y=深度, z)）

- 面板整体 **5.000 × 3.700**，宽:高 ≈ **1.35 : 1**（横置）。y=0 是盖板前表面，-y 向里。
- 前磨砂盖板：`(0,-.095,1.85)` 尺寸 `5 × .016 × 3.7`。
- 后透光载板 `4.97×3.68`、信息基板 `4.80×3.47`、四条抛光围栏。
- **大光学腔**：中心 `(-.425, 1.80)`，外半径 ~.918（大环）；配折射肩、内斜面、3 圈同心车削线、径向接缝、84 根立面细立筋。
- **小光学腔**：中心 `(1.125, 2.455)`，外半径 ~.555（右上）；配琥珀环 + 轮毂 + 52 根立筋。
- **琥珀环**：大环 2 段弧（109°–225°、229°–364°），小环整圈 + 下沿束带 —— 这是"进度环"。
- **光学双连接带**（ribbon）：两条近透明曲带，从左下 `(0.31,1.16)→(0.99,1.33)→(1.00,1.78)→(0.73,2.20)` 流向右上，配切线导槽 —— "音频流"。
- **序列标签块**（左上）：`(-1.36, 3.04)` 尺寸 `.99×.41`，上有 "RHINE LAB, LLC." / "INTERNAL DATABASE" / "NO.001" 三行。
- **黄铜索引条**：左上 `case_point(92,26)` 竖条 `Index_Inlay`，沿左缘向下（品牌/当前高亮）。
- **外框刻线**：外上左、外下右、上电路、左勾、内框、下回返、底搭扣，压槽高光。
- **两枚钛螺丝**：右上 `(999,37)`、左下 `(57,642)`（像素坐标），C 形压槽 + 十字槽螺头。
- **校准刻度**：左缘 25 条短刻线（每 5 条一条长线）—— 时间轴/刻度。
- **排气**：16 条激光蚀刻排（右下）+ 11 条对角排气槽 —— 频谱条。
- **竖排凸字**："RHINE LAB, LLC." 沿左缘向下（品牌竖排）。
- **服务插座**：右下 `(1312,923)` 圆孔 + 香槟中心 —— 设置/菜单钮。
- **注册垫片**：`(-1.61,-1.45)` 两个小香槟块。

## 4. 摄影棚（setup_studio.py）

- 相机 `Asset_Review_Camera`：正交（ORTHO），位置 `(-7,-11,6)`，看向 `(0,0,1.9)`，`ortho_scale=7.3`。
  → 前左上方 3/4 视角，正投无透视；终端在画幅内带边距居中。
- 世界 `Warm_Studio_World`：背景色 `(.8,.77,.72)`（暖灰 #CCC4B8），强度 .65。
- 3 盏 AREA 盘灯（对准 `(0,0,2)`）：
  - Softbox_Key `(-4,-5,8)` 950W size 7
  - Softbox_Rim `(5,1,6)` 1100W size 5
  - Softbox_Fill `(1,-7,3)` 350W size 6
- Cycles 48 采样 + 降噪，输出 1200×1000。

## 6. 落地原则

- 播放器界面 = 这台档案终端本身：Three.js 渲染 `archive-assembly.glb`，
  相机/灯光照搬第 4 节；材质用第 2 节 hex。
- 文字与控件叠在终端对应部件上，用 `Carbon_Ink #060706`（深）/ `#EFF1F2`（浅）做文字，
  `Champagne_Index #A3754A` 做高亮，`Amber_Optical_Inlay #7A2E0D` 做播放/进度点亮。
- 后端沿用现有 Electron（`app/main.js` + `app/preload.js`）的库/NCM/B站/媒体键/音频 IPC，不改。
