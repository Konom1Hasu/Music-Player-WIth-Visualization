# 快捷键

快捷键分三层：媒体键（系统级）、全局备用组合键（系统级）、应用内快捷键（窗口聚焦时）。

---

## 1. 媒体键（系统级）

窗口在后台、最小化，甚至正在跑无边框全屏游戏时都有效。

| 键名 | 典型触发方式 | 功能 |
| --- | --- | --- |
| `MediaPlayPause` | 键盘播放键、多数耳机单击 / 双击 | 播放 / 暂停 |
| `MediaNextTrack` | 耳机双击 / 三击、键盘下一曲 | 下一首 |
| `MediaPreviousTrack` | 耳机长按 / 三击 | 上一首 |
| `MediaStop` | 键盘停止键 | 暂停 |
| `MediaPlay` | 部分耳机 / 声卡驱动的独立播放键 | 播放 |
| `MediaPause` | 部分耳机 / 声卡驱动的独立暂停键 | 暂停 |

六个键全部注册：部分耳机把「播放 / 暂停」拆成 `MediaPlay` 和 `MediaPause` 两个键发送，而不是 `MediaPlayPause`。

### 媒体键是独占资源

Windows 的媒体键同一时刻只能被一个程序注册，游戏或其它音乐软件先注册，本程序就拿不到。设置面板 →「`HEADPHONE / MEDIA KEYS`」那一行看状态：

| 显示 | 含义 |
| --- | --- |
| `媒体键 ✓ 已接管` | 六个键全部注册成功 |
| `✕ 被占用` + `未拿到：…` | 有一部分被抢走，后面列出**具体键名** |
| `✓ 备用组合键可用` | §2 那套组合键可用 |
| `最近一次：播放 / 暂停 · 来源 MediaPlayPause · 12:52:04` | 刚按下的键被系统认成了哪一个 |

每 **6 秒**重试一次失败的键（成功的不重复注册），关掉冲突程序后会自动恢复。

## 1.5 有线耳机按键

耳机线控的按键不是键盘按键，走系统的「消费者控制」通道，由 Windows 翻译成媒体键再发给前台程序。

| 耳机上的操作 | 系统发出 | 本程序的动作 |
| --- | --- | --- |
| 单击（中键） | `MediaPlayPause` | 播放 / 暂停 |
| 双击 | `MediaNextTrack` | 下一首 |
| 三击 | `MediaPreviousTrack` | 上一首 |
| 长按 | 多数固件直接走系统语音助手 | 拿不到 |
| 音量键 | `VolumeUp` / `VolumeDown`（系统接管，本程序不抢） | 系统音量 |
| 接听键 单击 | `MediaPlayPause`（多数固件） | 播放 / 暂停（= 接听 / 挂断） |
| 接听键 长按 | `MediaStop`（部分固件） | 暂停 |
| 结束通话键 | `MediaStop` | 暂停 |

### 怎么确认「我的耳机键被认成了什么」

1. 打开设置面板 → 看 `HEADPHONE / MEDIA KEYS` 那一行；
2. 按一下耳机上的键 → 右侧会写**动作 · 来源键名 · 时间**，例如 `下一首 · 来源 MediaNextTrack · 12:52:05`；
3. 如果按键毫无反应、那一行也不动，说明这个键：
   - 被别的程序（游戏、其它播放器）抢走了 → 看自检行里「未拿到」的键名，关掉冲突程序等 6 秒自动重试；
   - 或它压根没走媒体键通道（少数固件把多功能键发成厂商私有指令）→ 用 §2 的备用组合键。

### 接听 / 挂断那颗键

很多线控只有一个多功能键，它在 Windows 上通常已被系统翻译成媒体键（见上表），多半本来就能用。按下去没反应，最常见的原因不是本程序没接，而是那颗键被别的程序截走了——尤其是 Windows 的「手机连接 / Phone Link」、通讯软件（微信 / QQ / Discord）或耳机自带软件，它们把接听键当成「接电话」用。按一下键弹出的是那些程序的窗口、而 `HEADPHONE / MEDIA KEYS` 那行不动，就是这种情况。

两个办法：

1. 关掉 / 退出抢键的程序（手机连接最常抢），等 6 秒本程序自动重试拿到；
2. 或用耳机配套软件把接听键改绑成组合键，为此留了两个语义明确的：

| 耳机按键想做的事 | 建议绑成 |
| --- | --- |
| 接听（播放 / 继续） | `Ctrl` + `Alt` + `A` |
| 挂断（暂停） | `Ctrl` + `Alt` + `H` |

按下时设置面板那行会显示 `播放 / 暂停 · 来源 Ctrl+Alt+A（接听）`，一眼能确认绑对了。这两个键与 §2 的其它组合键一样是全局快捷键，窗口在后台、游戏在跑也生效。本程序不做键盘钩子去硬抢任何键（带反作弊的游戏会把全局钩子判定为外挂），所以厂商私有指令的按键无法接管，只能改绑。

### 耳机带「USB 声卡 / 配套软件」的情况

这类软件通常能把按键映射成任意键盘组合，直接绑 §2 那套即可，语义与耳机三键一一对应。

## 2. 全局备用组合键（系统级）

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl` + `Alt` + `Space` | 播放 / 暂停 |
| `Ctrl` + `Alt` + `→` | 下一首 |
| `Ctrl` + `Alt` + `←` | 上一首 |
| `Ctrl` + `Alt` + `↑` | 音量 +5% |
| `Ctrl` + `Alt` + `↓` | 音量 −5% |
| `Ctrl` + `Alt` + `A` | **接听**（播放 / 继续）—— 给耳机接听键改绑用 |
| `Ctrl` + `Alt` + `H` | **挂断**（暂停）—— 给耳机挂断键改绑用 |
| `Ctrl` + `Alt` + `P` | 播放 / 暂停（别名） |
| `Ctrl` + `Alt` + `N` | 下一首（别名） |
| `Ctrl` + `Alt` + `B` | 上一首（别名） |

### 迷你悬浮窗控制

在独占全屏或原始输入的游戏里，悬浮窗收不到鼠标事件（系统层面限制），此时用这些键操作。方向键加了 `Shift`，把 `Ctrl+Alt+←/→` 让给耳机的上一首 / 下一首。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl` + `Alt` + `Shift` + `←` | 迷你窗左移 14 px |
| `Ctrl` + `Alt` + `Shift` + `→` | 迷你窗右移 14 px |
| `Ctrl` + `Alt` + `Shift` + `↑` | 迷你窗上移 14 px |
| `Ctrl` + `Alt` + `Shift` + `↓` | 迷你窗下移 14 px |
| `Ctrl` + `Alt` + `0` | 迷你窗放大（宽高各 +20 px） |
| `Ctrl` + `Alt` + `9` | 迷你窗缩小（宽高各 -20 px） |
| `Ctrl` + `Alt` + `L` | 锁定 / 解锁迷你窗（锁定后忽略指针事件，防误触） |

## 3. 应用内快捷键（窗口聚焦时）

两套按键不一样：主界面是音乐档案终端；旧版独立播放器界面只在 `app/ui` 构建产物缺失时作为兜底加载。

### 3.1 主界面：音乐档案终端

| 快捷键 | 功能 |
| --- | --- |
| `←` `→` | 切换档案分组（列） |
| `↑` `↓` | 前后翻档案（同一列内，可循环） |
| `Enter` | 档案阵列里：**打开档案并播放**（进详情 + 起播当前这一首）；已在详情里：**播放 / 暂停这一首**。开屏阶段按 `Enter` 直接进系统 |
| `/` | 打开曲目检索（`TRACK INDEX`） |
| `Esc` | 按优先级：关弹窗 → 收起歌曲编辑面板 → 从详情回到档案阵列 |

设置面板里给出的就是这一行：`←` `→` 切列　`↑` `↓` 选档　`ENTER` 读取　`/` 检索　`ESC` 返回。

**什么算「正在打字」**：只有真的会吃字符的控件——文本框、文本域、下拉框、可编辑区。进度条与音量条不算：拖过它们之后光标停在上面，回车、方向键、`/` 依旧可用。

### 3.1.1 鼠标：播放条与播放列表上的点击

| 点哪里 | 结果 |
| --- | --- |
| 播放条的**曲名 / 艺术家**那一块 | **打开这一首的档案**（只切画面与选中态，不改变播放状态） |
| 播放条的**其它位置**（频谱那一块等） | 回到档案阵列 |
| 播放条上的按钮（播放暂停 / 上一首 / 下一首 / 收藏 / 导入 / 列表…） | 各按钮自己的功能，**不会**被当成「打开档案」或「返回」 |
| 进度条、音量条 | 拖拽调整 |
| 弹窗开着时点播放条 | 先收掉弹窗 |
| 播放列表里**点曲名那一行文字** | 播放这首**并打开它的档案**（无视 `OPEN ARCHIVE ON PLAY` 偏好） |
| 播放列表里点行内其它空白处 | 只播放（是否打开档案看 `OPEN ARCHIVE ON PLAY`） |
| 播放列表行的 `↳` / `♡` / `✕` | 下一首播放 / 收藏 / 移除 |

### 3.2 旧版独立播放器界面（兜底）

| 快捷键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `→` | 快进 5 秒 |
| `←` | 后退 5 秒 |
| `↑` | 音量 +5% |
| `↓` | 音量 -5% |
| `M` | 打开 / 关闭迷你悬浮窗 |
| `L` | 展开 / 收起播放列表面板 |
| `F` | 收藏 / 取消收藏当前歌曲 |
| `Esc` | 关闭歌曲编辑弹层 |
| `Enter` | 在歌曲编辑弹层中保存（光标在文本输入框时） |

## 4. 快捷键失效排查

1. **设置面板 →「媒体键」自检行**：`✓ 已注册` 说明快捷键本身没问题，去查耳机 / 键盘固件或电量；`⚠` / `✕` 说明有程序抢占，关闭游戏或别的音乐软件，等 6 秒自动恢复。
2. **游戏是否为独占全屏**：独占全屏下窗口无法置顶、收不到鼠标事件，请改为「无边框窗口」。
3. **是否被安全软件拦截**：某些安全软件会阻止注册全局热键，把本程序加入白名单。
4. **NCM 解密组件是否被杀软隔离**：只影响 NCM 解密，不影响快捷键。
