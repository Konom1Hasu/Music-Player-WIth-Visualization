# 音乐播放器 · Music Player

**当前版本 v1.4.3** ｜ [更新日志](docs/更新日志.md) ｜ [数据管控说明](docs/数据管控与合规.md) ｜ [维护指南](docs/维护指南.md)

一个基于 **Electron** 的便携式桌面音乐播放器：本地曲库管理、自定义频谱可视化、沉浸式全屏封面歌词页、
可悬浮于游戏之上的迷你悬浮窗，以及耳机线控 / 媒体键支持。

界面为中文，走「干净圆角 + 极简线性图标」路线，内置深色 / 浅色 / 网易云红 / 莱茵生命四套主题。

> 本项目只做本地播放，不包含任何在线音乐源。B 站缓存提取仅用于播放**你本机已缓存的音频**。
> 对解出的音频，程序采取「不落盘 / 不可导出 / 可追溯」三层管控，详见
> [数据管控与合规](docs/数据管控与合规.md)。

## 特性

### 播放与曲库

| 能力 | 说明 |
| --- | --- |
| 多来源导入 | 选择文件、选择文件夹（递归）、直接拖拽到窗口 |
| B 站缓存提取 | 自动扫描本机 B 站客户端缓存，提取音频并补齐标题 / 歌手 / 封面（副本仅存于会话临时目录） |
| NCM 解密 | 内置 `ncmdump`，导入网易云 `.ncm` 时自动解密为 mp3 / flac，保留完整 ID3（结果只在内存中） |
| 播放模式 | 列表循环 / 顺序播放 / 单曲循环 / 随机播放 |
| 进度记忆 | 关闭后再次打开自动恢复到上次的歌曲与播放位置 |
| 队列控制 | 「下一首播放」插入队列，支持拖动排序 |
| 倍速播放 | 0.5× ~ 2.0× |

### 元数据

- 标题 / 歌手 / 专辑 / 封面：优先读取音频内嵌 ID3 标签，回退到文件名解析与同目录 `cover.*`
- **多歌手识别**：`A/B`、`A、B`、`A feat. B`、`A & B` 等写法全部拆分为独立歌手
- **重新识别**：对已导入的歌曲一键重跑识别，歌手信息更新后立即可用
- 封面支持内嵌图、文件夹图片，NCM 文件亦可直接取出封面

### 歌词

- 支持 `.lrc` 同名歌词、内嵌歌词、UTF-8 / GBK 编码自动识别
- 网易云式逐行滚动高亮，支持翻译行
- 找不到歌词时自动在同目录与歌名相似文件中匹配

### 可视化

自研频谱分析器，完全脱离常规 `AnalyserNode` 的等宽频段方案：

- 前后处理：Hann 窗 + Goertzel 精确取点，`SPECTRUM_N = 1024` 点 FFT 级精度
- 对数频率分带，120 条柱状条，低频到高频不再被「挤在左边」
- 峰值归一化 + 对数压缩，安静段与爆音段都有视觉动态
- **鼓点响应**：低频能量动态参考值 + 乘性泵浦，鼓点到来时整排柱体明显弹起
- **高耸条**：低频峰值自动定位到柱体序列的左边缘，配合倾斜因子形成尖细高峰
- **滑动感**：相干行波叠加（右 → 左约 12 条/秒），而非无方向的随机抖动
- 分析放在 Web Worker 中，主线程零阻塞；Worker 不可用时自动降级为同步计算

### 迷你悬浮窗

- 一键从主窗口弹出，**复用主窗口已算好的可视化数据**（不重复计算）
- 置顶层级为 `screen-saver`，可在**无边框窗口模式的游戏**之上显示
- `setFocusable(false)`：点击**不会**让游戏失焦
- 支持拖动、缩放、透明度、锁定位置（防误触）
- 主窗口被遮挡 / 后台时仍保持全速渲染（关闭了各类后台节流）

### 系统集成

- **媒体键 / 耳机线控**：`MediaPlayPause`、`MediaNextTrack`、`MediaPreviousTrack`、`MediaStop`
  通过 Electron `globalShortcut`（RegisterHotKey）+ Chromium Media Session（SMTC）双通道接管
- 设置面板内置**媒体键自检**：显示 ✓ 已注册 / ⚠ 被占用 / ✕ 全部被占用，便于排查冲突
- 注册是**幂等**的，定时重试不会把已注册的键误判为「被占用」

### 主题与外观

- 深色（蓝紫）、浅色、网易云红（`#EC4141`）、**莱茵生命**（琥珀 `#c5a16b`）
- 莱茵生命是「仪器面板」变体：配色取自
  [RhineLabUI](https://github.com/LBEILC/RhineLabUI)（MIT）的暗色面规范，
  材质上配套 1px 实心细线、构件直角、**选中项用左侧黄铜竖条而非色块**、
  等宽数字与封面四角黄铜标记 —— 不只是换色，详见 [docs/功能说明.md](docs/功能说明.md#莱茵生命仪器面板变体)
- 所有弹层、滑槽、滑块、进度条把手均跟随主题
- 统一极简线性图标（16 套手写 SVG，`stroke-width: 1.7`，圆角端点）
- 圆角播放按钮与胶囊形暂停图标
- **封面 3D 档案**（莱茵生命主题下默认开启，⚙ 面板可开关）：封面区叠一层可旋转的
  [Rhine Lab 档案](https://github.com/LBEILC/RhineLabUI) 3D 模型（MIT），
  并支持**拆解 / 重组** —— 照搬原项目 `model-viewer.ts` 的部件分层规范
  （按 `assemblyPart` 分组、沿 Z 平移 `depth × spread`、阻尼速率 5.5）。
  转速与播放状态联动；限帧 30fps、窗口隐藏即停、失败自动关闭 —— 详见
  [docs/功能说明.md §10](docs/功能说明.md#10-封面-3d-档案)
- **MiSans 字体**：用 `local()` 按需命中，系统装了就用、没装自动回落，不内置字体文件

## 数据管控

程序能从 `.ncm` 与 B 站缓存里解出音频。这些**派生数据**受原平台版权约束，
一旦被随手复制出去就成了非法传播源。为此做了三层管控：

| 层 | 措施 |
| --- | --- |
| **最小落盘** | 解密结果只在**内存**中传递，绝不写入音乐目录；解出的音频只存在于 `%TEMP%\mp-session-<会话ID>\`，读完立即覆盖擦写，**退出程序即整体销毁**，崩溃残留下次启动清理 |
| **不可导出** | **不提供任何导出 / 另存为 / 分享**能力；28 个 IPC 通道没有任何一个接受"输出路径"；`preload` 不暴露写文件方法；渲染进程无 `nodeIntegration` |
| **可追溯** | 每次解密与提取写一条本机审计记录（时间 / 版本 / 会话 ID / 来源文件 / 产物体积），上限 500 条，可在设置面板查看条数并一键清空 |

输入侧也有限制：`convert-ncm` 先校验 `CTENFDAM` 容器魔数，不是真正的 NCM 直接拒绝
（因而它不是一个"通用解密器"）；B 站提取只处理本机已有缓存，不发起任何音频下载请求。

这些状态在程序内**可见**：⚙ 面板的「数据管控」行显示
`内存解密 · 会话级临时目录 · 无导出 · 审计 N 条`，首次启动还会弹出一次使用边界告知。

管控措施可回归验证：

```powershell
node scripts\数据管控验证.js app     # 16 项断言，含"从源码摘出擦除逻辑实测"
```

完整说明（含技术实现、验证明细与已知边界）见 **[docs/数据管控与合规.md](docs/数据管控与合规.md)**。

> **使用边界**：请仅将本程序用于个人本地播放你已合法获得的内容。
> 解出的音频请勿传播、分发或用于任何商业用途；由此产生的法律责任由使用者自行承担。

## 快速开始

### 从源码获取

```powershell
git clone https://github.com/Konom1Hasu/Music-Player-WIth-Visualization.git
cd Music-Player-WIth-Visualization

# 准备 Electron 运行时 + 同步源码（约 250 MB，首次需联网下载一次）
.\scripts\build-portable.ps1

# 运行
.\dist\音乐播放器-win32-x64\音乐播放器.exe
```

> 仓库出于体积考虑**不包含** Electron 运行时（约 222 MB，其中 `音乐播放器.exe` 单文件 172 MB，
> 超过 GitHub 的 100 MB 单文件上限）。首次构建会自动下载并解压，之后完全离线复用。

### 直接使用（免安装）

1. 下载或构建 `dist\音乐播放器-win32-x64\` 整个文件夹
2. 双击 `音乐播放器.exe`
3. 把音乐文件或文件夹拖进窗口即可

> 便携版**不需要安装**，整个文件夹可以放在 U 盘里带走。删除文件夹即完成卸载。

### 一键安装到本机

双击根目录的 `安装.bat`（或运行 `scripts\install.ps1`），会把程序安装到
`%LOCALAPPDATA%\Programs\音乐播放器`，并在桌面与开始菜单创建快捷方式。

## 界面布局

主界面为左右分栏：

```
┌──────────────────────────┬──────────────────────────────┐
│                          │  歌曲信息（标题 / 歌手 / 专辑）│
│        大封面图           ├──────────────────────────────┤
│       （左 52%）          │        歌词（逐行高亮）        │
│                          ├──────────────────────────────┤
│                          │   频谱可视化（右下半部分）      │
└──────────────────────────┴──────────────────────────────┘
       ↑ 左右之间为封面渐变模糊过渡（blur 64px + 饱和度提升 + 遮罩渐隐）
```

- 封面区域会向整屏渗出模糊背景，形成类似网易云全屏封面的过渡
- 可视化高度、左边界、柱体粗细与数量都可在设置面板中调整

## 构建

### 前置条件

- Windows 10 / 11 x64
- PowerShell 5.1 或更高
- 可选：Node.js（仅在需要自动下载 Electron 运行时用到网络时）

### 构建便携版

```powershell
# 在仓库根目录
.\scripts\build-portable.ps1
```

脚本会：

1. 校验 `app/` 下的必需文件
2. 检查 `dist\音乐播放器-win32-x64\` 是否已有 Electron 运行时
   - 有 → 直接复用（离线可用）
   - 没有 → 从镜像下载 Electron 31.7.7 win32-x64 并解压
3. 清空并重建 `resources\app`，把 `app/` 完整复制进去
4. 打印产物路径与体积

也可以直接双击根目录的 `构建.bat`。

### 自定义运行时版本

```powershell
.\scripts\build-portable.ps1 -ElectronVersion 31.7.7 -Mirror https://npmmirror.com/mirrors/electron
```

## 安装

```powershell
.\scripts\install.ps1
```

行为：

1. 调用构建脚本确保产物存在
2. 复制到 `%LOCALAPPDATA%\Programs\音乐播放器`（已存在则先清空）
3. 创建桌面快捷方式与开始菜单快捷方式
4. 在同目录写入 `卸载.ps1` / `卸载.bat`
5. 可选 `-Launch` 参数，安装完直接启动

```powershell
# 安装并立即启动
.\scripts\install.ps1 -Launch
```

卸载：运行安装目录下的 `卸载.bat`，或直接删除该文件夹。

## 版本回滚

`versions/` 里保存了 `musicplayer.html` 历史上 12 个关键节点的**逐字节快照**
（从 DSH 会话日志反向重放还原，204 处编辑 0 失败），用于可视化效果调坏了快速退回已知可用状态。

```powershell
# 列出全部版本（同时显示当前用的是哪一个）
.\scripts\use-version.ps1 -List

# 回滚到某个版本（自动备份当前版本 → 替换 → 重新构建）
.\scripts\use-version.ps1 -Version Q1
```

`-Version` 接受完整文件名（`Q1_preWave.html`）、前缀（`Q1`）或关键字（`preWave`），唯一匹配即可。

- 执行前会把当前 `app/index.html` 备份到 `dist\版本备份\`，随时可切回
- 切回最新开发版：`git checkout -- app/index.html`，或 `-Version <备份文件名>`
- `-NoBuild` 可只换源码不重新构建

这些快照都是自包含单文件 HTML，只调用当前 `preload.js` 里仍存在的 IPC，
因此**可以直接当 `app/index.html` 跑**，不需要一并回滚 `main.js`。
代价是它们不认识后来加入的 B 站缓存、迷你悬浮窗、多歌手识别等功能。

版本对照表、兼容性说明与一段已被推翻的历史约束记录见 [versions/README.md](versions/README.md)。

## 常见问题

**Q：为什么 GitHub 仓库里没有 `音乐播放器.exe`？**

Electron 运行时约 222 MB，远超 GitHub 单文件与仓库的合理体积。仓库只保存源码、脚本与文档，
运行时由 `scripts\build-portable.ps1` 在本地准备（已有本地运行时则完全离线，无需联网）。

**Q：媒体键（耳机按键）没反应？**

打开设置面板看「媒体键」一行：

- `✓ 已注册` → 已成功接管
- `⚠ 被占用` → 部分键被其它程序（游戏、音乐软件）抢走
- `✕ 全部被占用` → 全部被抢走，请关闭冲突程序，或改用应用内快捷键

Windows 的媒体键是**独占**资源，同一时刻只能由一个程序注册。

**Q：迷你窗在游戏里看不见？**

- 游戏设为「无边框窗口 / 窗口化全屏」时，迷你窗可以正常显示在最上层
- 游戏使用**独占全屏**（Exclusive Fullscreen）时，任何普通窗口都无法覆盖，这是 Windows 的限制；
  请在游戏里把显示模式改成无边框窗口

**Q：切换歌曲后封面不刷新？**

在设置里点一次「重新识别」，或删除该曲目重新导入。

**Q：频谱柱体不动 / 很平？**

确认播放的是有低频内容的曲目；可在设置面板里调整可视化灵敏度、鼓点响应强度与柱体数量。
